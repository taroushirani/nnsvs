# README

Code in this directory was adapted by https://github.com/gwx314/TechSinger.

The flow-matching (rectified flow) formulation follows TechSinger's pitch/mel
predictors (Guo et al., "TechSinger: Technique Controllable Multilingual Singing
Voice Synthesis via Flow Matching", https://arxiv.org/abs/2502.12572).

The denoiser (`nnsvs.diffsinger.DiffNet`) is shared with the DiffSinger-derived
code in `nnsvs/diffsinger`.
